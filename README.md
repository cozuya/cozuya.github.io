# cozuya.github.io

Source for <https://cozuya.github.io/>, the personal site of Chris Ozols.
It is a small static site generated by `build.py` (Python standard library
only) and deployed to GitHub Pages by `.github/workflows/pages.yml`.

```sh
python3 build.py          # writes _site/ and fails on invalid content
python3 -m http.server -d _site 8000
```

## Layout

| Path | Purpose |
| --- | --- |
| `content/site.json` | Name, links, collection titles and introductions |
| `content/proofs/<slug>.json` | One file per proof, published at `/proofs/<slug>/` |
| `content/refutations/<slug>.json` | One file per refutation, published at `/refutations/<slug>/` |
| `static/` | Copied unchanged (stylesheet) |
| `build.py` | Generates every page, `sitemap.xml`, `robots.txt`, and JSON-LD |
| `indexnow.py` | Notifies IndexNow search engines of new or changed URLs |

## Adding a result

Copy an existing record into the right collection, name it `<slug>.json`, and
edit it. Index pages, the sitemap, breadcrumbs, and structured data update
automatically. Keys ending in `Html` hold trusted HTML; other strings are plain
text.

Common fields: `slug`, `publicationStatus` (`published` or `draft`), `order`,
`title`, `shortTitle`, `description` (meta description), `summary`,
`dateModified`, `keywords`, `problem` (`name`, `identifiers`, `alternateNames`,
`sourceHtml`, schema.org `citations`), `verification` (`trustModel`,
`summary`), `priority`, `repository`, and grouped `links`. An optional
`scopeWarningHtml` is shown prominently above everything else.

- Proofs also need `statementHtml`, `scopeHtml`, `proofOutlineHtml`,
  `verificationHtml`, `priorArtHtml`, and `provenanceHtml`.
- Refutations need `claimHtml`, `counterexampleHtml`, `explanationHtml`,
  `verificationHtml`, `priorArtHtml`, and `provenanceHtml`.

`verification.trustModel` is one of `lean-kernel`, `lean-native-decide`, or
`computation`. The page prints a fixed label for it, so an unformalized
computation is never shown as Lean-verified.

`priority.priorResolutionKnown` must be `true` when an earlier proof or
refutation is known. The record must then list it in `priority.earlier`, and
the build fails if the record says anywhere that no earlier result was found.
The build also rejects promotional wording.

This repository is public. `draft` only keeps a record off the generated
site, so do not commit unpublished drafts here.

## Search engines

`robots.txt` allows crawling and points to `sitemap.xml`. The file
`<indexNowKey>.txt` at the site root verifies IndexNow submissions (Bing and
other participating engines). After a deployment that adds or changes pages,
run `python3 indexnow.py URL...`, or `python3 indexnow.py --all` to submit
every URL in the sitemap.
